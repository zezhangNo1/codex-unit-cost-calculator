# Codex 单位成本计算器

把 Codex 的**档位倍率 × 区域实付价 × 重置红利**合成一个可比较的数字：**每 1 美元买到多少产能**。

同类站点都在回答「什么时候重置」，这个项目回答「这笔钱花得值不值」。

---

## 核心洞察

官方只公布**倍率**（Plus 1× / Pro 5x 5× / Pro 20x 20×），从不公布「每月等于多少 credits」的绝对值。一旦把倍率当分母，两个结论立刻显形：

| 档位 | 月费 | 倍率 | 名义单位成本 | 结论 |
|---|---|---|---|---|
| ChatGPT Plus | $20 | 1× | **$20.00** | 基准 |
| Pro 5x | $100 | 5× | **$20.00** | 单位成本与 Plus **完全相同** —— 买到的是更高的绝对上限，不是更便宜的单位 |
| Pro 20x | $200 | 20× | **$10.00** | 单位成本腰斩 |

第二个结论：**「升档位」和「换区域」是两条等效路径** —— 官方 Pro 20x 单价 $10.00，与菲区 Plus 的 $9.76 几乎相同，但一个是每月 $200 现金流门槛，一个是封号风险。

而重置是**全局事件**，对所有档位等比例生效，因此**不改变排序，只压低绝对水位**。所以它在本项目里只是一个滑块，不是首页的大时钟。

## 为什么不用数据库（重要）

**第一版刻意不引入数据库，纯静态页面就够。** 理由：

| 需求 | 静态方案是否够用 | 说明 |
|---|---|---|
| 计算器 | ✅ 够 | 全部计算在浏览器完成，无服务端状态 |
| 价格与档位数据 | ✅ 够 | 存在 `assets/data.js`，**git 就是数据库**，每次改动都有版本历史 |
| 数据更新频率 | ✅ 够 | 区域价格双周更、官方倍率月更，人工改文件后 push 即可 |
| 价格历史曲线（P1） | ✅ 够 | 在 `data.js` 里给每条价格加 `history: [{date, usd}]` 数组即可 |
| 邮件 / Telegram 订阅 | ⚠️ 不自建 | 交给第三方表单服务（Formspree / Buttondown 等），**不自己存用户数据** |
| 用户账号 / 自选关注列表 | ❌ 不够 | 属于 P2，届时再引入后端 |
| 众包价格提交 | ❌ 不够 | 需要审核与防滥用，属于 P2 |

**好处：** 零服务器成本、零数据库运维、攻击面几乎为零（没有可拖库的数据）、可直接免费部署到 GitHub Pages。

**代价：** 无法做个性化功能。但这在 MVP 阶段不重要——这个产品的核心价值是**数据可信度**，不是功能丰富度。

**唯一非静态的部分是订阅表单。** 建议接第三方服务，这样用户邮箱不进你的数据库，合规负担最小。接入方式：

```html
<!-- index.html 里的表单，填上第三方服务给你的 endpoint 即可 -->
<form class="cta" id="subForm" data-endpoint="https://你的表单服务/xxx">
```

未填 endpoint 时，表单会明确提示「订阅后端尚未接入」，不会假装提交成功。

## 维护数据

只改一个文件：`assets/data.js`。

```js
{
  id: 'PH',                                  // 区域代码
  name: '菲律宾区',
  pending: false,                            // true = 尚未采集，页面会显示「数据缺失」
  prices: {
    plus: {
      usd: 15.40,                            // 折美元（计算用）
      local: '¥109.82 / ₱1,200',             // 本币标价原文
      caliber: 'iOS App Store（多来源冲突）',  // 必须写清是 Web 还是 App Store
      source: '中文公众号 / itscheaper.in',
      url: '',
      fetched: '2026-08-11',                 // 抓取日期，护栏指标依赖它
      conf: '低',                             // 高 / 中 / 低
      note: '三个来源相差近 2 倍，取中位口径，不构成事实。'
    }
  }
}
```

**维护铁律：**

1. **抓不到就留空**（不要写进 `prices`），页面会显示「数据缺失」。**绝不用推算价填补。**
2. **`caliber` 必须写清口径**（Web / iOS App Store / Google Play / 未标注）。读不懂口径的价格就是不可用的价格。
3. **`fetched` 必须真实**。页面底部有陈旧度护栏：超过 45 天未更新的条目占比超过 20% 时，数据应视为不可用。
4. **多来源冲突时全部列出**，取中位口径用于计算，并在 `note` 里说明冲突。

## 合规红线（不可逾越）

| 红线 | 规则 |
|---|---|
| 定位 | 只做**信息聚合与对比**，不做攻略与教学 |
| 措辞 | 只陈述各地标价事实，**不给操作路径**（不写「如何换区」「用哪张卡」） |
| 免责 | 每条跨区价格旁必须保留官方机制说明（见下） |
| 广告 | 跨区省钱类内容可能触发广告联盟拒审 → MVP 期不接广告，先跑订阅 |
| 数据 | 不展示任何未经核验的推断价 |

**必须保留的官方机制说明：**

- OpenAI 按**支付方式所属国家**定价，**不是按 IP**
- 因此 VPN 换区虽然能看到低价，但**结账会失败**
- 需要真实的当地支付方式，通常要求当地居住身份
- 跨区订阅在 Apple / Google / OpenAI 条款中属灰色地带，**存在封号案例**

## 局限性

- 月费为**估算值**，以付款页实际显示为准
- 倍率是官方倍数，**不是额度绝对值**；本站不换算成 token
- 重置利用率是**用户自评参数**，不是客观事实
- 重置红利对所有档位等比例生效，**不影响排序**
- 折美元使用来源方给出的汇率，**不是统一时点汇率**，跨来源比较有系统性误差
- 置信度只衡量「口径与时间戳是否明确」，**不代表该区域可正常订阅**
- 本站**不构成投资或订阅建议**
